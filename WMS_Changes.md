# Cambios propuestos despues de presentar aplicacion 23/10/2026

## Entradas como lista al crear Salidas
Al generar una salida que las entradas se presenten en forma de lista vertical sin imagenes. Conteniendo datos sobre la entrada como:
- Numero de Entrada
- Cliente
- Numero de Bultos
- Fecha de Entrada

## Al generar o modificar una salida, los bultos muesten guia

## Codigo de barras que sirva para verificar bultos siendo subidos a transporte.
Este deberia marcar error si alguno falta o si algun bulto se envio por equivocacion.

## Multiples imagenes en una Entrada
Las Imagenes deberian ser asignadas a la Entrada madre en vez de a los bultos individuales.

## Cantidades y Bultos
Esto aun se debe definir pero se presento la idea de que los bultos se puedan replicar para cumplir cantidades, removiendo el uso de el campo cantidad y en vez copiando bultos hasta que estos cumplan la cantidad requerida. Solo entonces esta se podra guardar como Entrada completa.

## Modificar bultos desde Entradas Detalles Bultos
Actualmente los bultos se tienen que eliminar si estos se quieren modificar. Se pide que estos se puedan modificar populando primero los datos de el bulto seleccionado en los campos donde pueden ser cambiados y posteriormmente guardados con el boton Guardar Detalles

## Filtrar por cliente al generar reportes
Al generar reportes de los siguientes datos:
- Entradas
- Salidas

Se pueda filtrar por clientes en adicion a por fecha.

## Guias multiples en campo de Entrada
Al generar una entrada que el campo de guias sean multiple lineas. Esta implementacion podria ser compleja ya que el systema de verificacion esta porjecta para usar guias, tal vez se tenga que cambiar a usar numero de identificacion de bulto en vez.

## Generar PDF del reporte de Entrada y Salida
Dentro de la pagina donde modificamos una entrada o salida, se pueda generar un PDF con un boton, que este se guarde en el sharepoint bajo Documentos_Entradas bajo el folder especiico a la entrada. Bajo salidas se deberia crear un Document Library donde se guarden archivos asociados a una salida.

## Campos con Memoria
Al generar una Entrada o Salida, se pide la capacidad de escribir en los campos como Transportista. Despues al guardar esta entrada, si el campo es nuevo o no esta registrado, que este se guarde automaticamente y en futuras ocaciones que sea sugerido.
